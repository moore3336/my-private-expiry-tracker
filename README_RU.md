# Трекер сроков годности

Персональное веб-приложение с отдельными аккаунтами пользователей, PostgreSQL и управлением запасами продуктов.

## Возможности

- Регистрация по логину и паролю, вход и выход из аккаунта.
- Личные списки продуктов с датами годности, категориями, поиском и фильтрами.
- Импорт и экспорт списка в JSON.
- Личный каталог продуктов и расчёт даты окончания хранения.
- Справочник внешних продуктов Open Food Facts.
- Мониторинг пищевых ГОСТов с официального портала.
- История действий, поддержка и административная панель.
- Персональные темы: цвет, фон, анимация и собственное изображение.

## Запуск

Требуется Node.js 20+ и PostgreSQL.

```bash
npm install
```

Скопируйте `.env.example` в `.env` и укажите как минимум:

- `DATABASE_URL` — строка подключения к PostgreSQL.
- `SESSION_SECRET` — длинный случайный секрет для сессий.
- `NODE_ENV=production` для production-развёртывания.
- `PORT` — порт сервера (Railway передаёт его автоматически).

Запуск:

```bash
npm start
```

При старте сервер создаёт недостающие таблицы и индексы. Существующие пользовательские данные не удаляются.

## Необязательные интеграции

- ИИ-поддержка: `OPENAI_API_KEY` и, при необходимости, `OPENAI_MODEL`.

Никогда не добавляйте реальные секреты в Git и не отправляйте их в чат. Храните их в защищённых переменных окружения хостинга.

## Проверка состояния

- `GET /health` — проверка соединения с PostgreSQL.

## Безопасность и данные

- Пароли локальных аккаунтов хранятся в виде bcrypt-хешей.
- Сессии хранятся в PostgreSQL; cookie в production использует Secure и HttpOnly.
- API личных данных требует авторизации и ограничивает запросы данными текущего пользователя.
- Не публикуйте базу данных, секреты или резервные копии.
